# INDmoney Capture Extension

This local Chrome extension adds a `Capture portfolio` button to visible INDmoney pages.

## Install once

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Select **Load unpacked**.
4. Choose this `indmoney-extension` folder.
5. Keep the deployed Expense Tracker Settings page open.

## Use

1. Click **Connect INDmoney** in Expense Tracker.
2. Log in to INDmoney and complete OTP/2FA yourself.
3. Open the portfolio, holdings, or asset allocation page.
4. Click **Capture portfolio** in the blue button added by the extension.
5. The snapshot is sent to the already-open Expense Tracker tab and saved automatically.

The extension reads only visible page text/tables. It does not read passwords, OTPs, cookies, or browser storage.
